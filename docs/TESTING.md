# Manual testing checklist

自動テストでは座標計算を確認します。Win32の実際の合成、DPI、タスクバー動作は実機で次を確認してください。

## 起動と常駐

- 初回起動で即座に選択画面が出る
- 選択後もタスクバーのRustptureが最小化状態で残る
- タスクバーアイコンのクリックで選択画面が再表示される
- `--background` では選択画面を出さず常駐する
- 2回目の `--capture` は既存プロセスで選択を開始し、2個目の常駐プロセスを残さない
- `--quit` で全ウィンドウとプロセスが終了する

## 範囲選択

- 左上から右下、右下から左上の両方向で選択できる
- `Esc` で画像を作らず閉じる
- 1ピクセル程度の誤クリックでは画像を作らない
- 選択用の黒い膜や白枠がキャプチャ画像へ混ざらない
- 左側・上側にある負座標モニターでも正しい範囲を取得する

## ピン留め画像

- 枠なしで表示される
- 初期状態で常に手前にある
- 左ドラッグで滑らかに移動する
- ホイールでカーソル位置を保って拡大・縮小する
- `Ctrl` + ホイールで透明度が変わる
- 左ダブルクリックで100%へ戻る
- 右クリックメニューがマウス位置に出る
- 画像を複数作成できる
- クリップボードへコピーした画像をペイント等へ貼り付けられる

## DPIとモニター

次の組み合わせを推奨します。

- 100% + 150%
- 125% + 200%
- 横置き + 縦置き
- 主モニターの左側または上側に副モニター

確認事項：

- モニターをまたいでも画像内容が切り替わらない
- ウィンドウの物理ピクセル寸法とズーム率が勝手に変わらない
- 「画面に合わせる」が現在のモニターの作業領域に収める
- 「画面内に戻す」で少なくとも32ピクセル分が見える位置へ戻る

## 性能測定

常駐後の体感経路を測る場合は、コントローラーがメッセージを受けた時点とオーバーレイの最初の `WM_PAINT` の時点へ `QueryPerformanceCounter` を追加してください。冷起動と常駐後の表示を分けて記録します。
